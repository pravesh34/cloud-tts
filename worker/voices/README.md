# Reference voices

Chatterbox clones the voice in these files. Drop two clean recordings here:

- `male.wav` — 10–15 seconds, one male speaker
- `female.wav` — 10–15 seconds, one female speaker

Guidelines:

- WAV, 24 kHz or higher, mono preferred
- one speaker, no background music or noise
- normal speaking pace, natural tone
- only voices you have permission to use (your own, or public-domain audio)

Without these files the worker falls back to Chatterbox's built-in voice, so
everything still runs — it just won't sound like the voice you picked.

Kokoro voices (`male_fast`, `female_fast`, ...) do not use these files.
